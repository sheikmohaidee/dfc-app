3. Machine Setup & Command Reference

Step 1: Clone Repository & Install Dependencies

# Clone repository
git clone https://github.com/beez-apps/DFC-APP.git
cd DFC-APP

# Install all workspace dependencies
npm install

Step 2: Run Next.js Admin Web Locally

# Start dev server on http://localhost:3000
npm --prefix apps/admin-web run dev

# Run production static build verification
$env:NODE_ENV="production"; npm --prefix apps/admin-web run build

Step 3: Run Expo Mobile Apps

cd apps/mobile

# Start Expo Metro Bundler
npm run start
  • Press a for Android Emulator.
  • Press i for iOS Simulator.
  • Scan terminal QR code using Expo Go app on physical devices.

4. End-to-End Demo Walkthrough

1 Customer AI Ordering Customer App
Sign in as customer@dfc.test. Use Tamil voice input or upload a prescription photo. Gemini 2.5 Flash extracts items, prices them in integer paise, and displays the order tracking screen with a 4-digit Delivery OTP.
2 Admin Dispatch & Kanban Admin Web
Log in at dfc-app-bdb4e.web.app as admin@dfc.test. Drag and drop orders across the 4 Kanban pillars or switch to 3D spatial map view of Madurai.
3 EAN-13 Barcode Packing Vendor App
Log in as vendor@dfc.test. Tap EAN-13 SCANNER on an active order. Verify barcodes, batch numbers (B1042), and expiry dates (12/28) before marking ready for pickup.
4 Doorstep UPI QR Payment Rider App
Log in as rider@dfc.test. Open task and tap DOORSTEP UPI QR. Shows exact-amount SVG QR code for GPay/PhonePe scan or switch to cash mode with change breakdown down to ₹1 coin precision.

5. Building Standalone Android APK (EAS CLI)

To generate standalone .apk packages for physical device testing without Expo Go:

# Install EAS CLI globally
npm install -g eas-cli

# Login to Expo account
eas login

# Trigger Android Preview APK build
cd apps/mobile
eas build -p android --profile preview
